# Code review, maintainer lens: cake-pan-converter

Verdict: NOT ready to own for years yet. The core maths and the page shell are sound (8" to 9" round = 1.27, 9x13 = 117 sq in, no HTML injection, textContent used everywhere). But 6 must-fix bugs give silently wrong or broken output: the ingredient parser, the unit toggle and the shared-link decoder. Must-fix count: 6.

How checked: read all source, ran `npm test` (passes), probed calc.js in node with 40+ inputs, drove the built page in a browser on port 4402 (server stopped). Nothing in the site was edited.

# Code review, regression lens: cake-pan-converter

Verdict: core maths is correct (all spec checks and all 12 article table rows recompute), template rules hold, but 4 must-fix defects silently change or drop user numbers (unit toggle drift, "0 tsp", unscaled extra quantities, "8 1/2" read as 8).

Hand-checked OK: 8" to 9" round = 1.2656 (shows 1.27x); 9x13 = 117 sq in; 9x13 to two 8" = 0.859; two 8" to 9x13 = 1.164; 8" sq to 9x13 = 1.828; 9x13 to 9" sq = 0.692; 9" sq to 9x13 = 1.444; 12 cup bundt vs 9x13 = 0.740; 9x5 loaf = 45 sq in; 8"/9" round areas 50.3/63.6; article worked example (1 7/8, 1 1/4, 5/8, 2 1/2 eggs); FAQ numbers. Template: canonical on every page, `_headers` pages.dev noindex rules present, About/Privacy/Terms/Contact linked from footer and home, 404 has noindex and is not in the sitemap, GA4 and AdSense scripts absent when empty (no googletagmanager or googlesyndication in dist), ads.txt is a comment line.
